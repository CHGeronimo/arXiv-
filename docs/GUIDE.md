## 发现：六大来源

| 来源 | 说明 | 调度 | 去重方式 |
|---|---|---|---|
| **arXiv** | 分类订阅（如 cs.MA、cs.GT），抓取最新一期公告 | 每日凌晨（起始小时+错峰可调） | arXiv ID 精确 |
| **Crossref** | 期刊订阅（Nature、TPAMI 等 73 本），按 ISSN 查询最新 DOI | 同上 | DOI 别名 |
| **DBLP** | 76 个 CCF 会议（轮换覆盖，默认 7 天一轮） | 同上 | DOI + 标题+日期归一 |
| **OpenAlex** | LLM 两阶段关键词扩展（40-90 条查询），语义搜索 | 同上 | DOI 别名 + 标题+日期 |
| **Semantic Scholar** | 作者订阅（支持 ORCID 辅助查找） | 同上 | DOI / S2 PaperID |
| **引文追踪** | 以「必读 ∪ 点赞」论文为锚点追引用与被引 | 同上 | 同 OpenAlex |

### 跨源去重

同一论文从不同源进来（arXiv ID / DOI / OpenAlex W-id）在**入库时自动相认**：
- **别名集合**：id、DOI（小写）、arXiv ID（从 pdf/abs URL 提取）、arXiv DOI 转换
- **标题+日期归一**：小写去非字母数字后精确匹配同日论文
- 命中即**并入已有行**（补空缺字段、引用数取大），不重跑 AI

### 断档回补

daemon 停机 ≥2 天后，arXiv 爬虫自动按 `submittedDate:[起点 TO 今天]` 区间补抓错过的论文。

### 爬取层去重

已入库/已忽略的 DOI 在爬取层直接跳过（不下载元数据、不请求 OpenAlex 摘要回填），每晚上千次请求的成本直接节省。

## AI 流水线

```
本地预筛（零 token）→ 快筛（关思考 ~3s）→ 深度增强（开思考 15-25s）
       ↓ 不相关            ↓ 通过                ↓ 推荐必读/推荐
    ignored 池          深度增强            全文深读（ar5iv，可选）
                            ↓                      ↓
                       知识卡片提取              fulltext_analysis
                            ↓
                       知识图谱聚类
```

### 各阶段说明

| 阶段 | 模型配置 | 耗时/篇 | 输出 |
|---|---|---|---|
| **本地预筛** | 无 LLM | 0ms | 与研究方向零重叠→直接拒绝 |
| **快筛** | 关思考 | ~3s | 相关/不相关判定 + 一句理由 |
| **深度增强** | 开思考 | 15-25s | 中文 TLDR、动机/方法/结果/结论、双评分（相关度×质量 1-10）、四级推荐（must-read/recommended/reference/ignore）+ 推荐理由 |
| **知识卡片** | 关思考 | ~3s | 问题/方法/结果/关键词/与研究方向的关系 |
| **全文深读** | 开思考 | 30-60s | 六字段：方法实现/实验设计/关键结果/局限/可复现性/与研究方向的关系 |
| **聚类** | 关思考 | 批量 | 15-30 个研究主题聚类 + 问题域标注 |

### 评分归因

论文详情页显示「🎯 匹配你的偏好主题：xxx」——告诉你**为什么推荐**这篇论文（匹配了哪些你点赞/手动添加的主题）。

### 全文深读预算

- 仅对 `must-read` 和 `recommended` 级别的 arXiv 论文自动触发
- ar5iv 未渲染或返回占位页时自动跳过（待下轮重试）
- 非连续行文（不足 2000 字符）标记 `low_confidence`

## 反馈闭环

```
点赞/点踩/评语 → 评语学术化改写 → 主题提取（5-7 个短语）
      ↓                                    ↓
   feedback 表                    liked/disliked_topics（各≤100）
      ↓                                    ↓
   feedback_notes（最近20条）      ┌──── 注入评分提示词（最高优先级信号）
   直通 AI 评分模板                └──── 注入关键词挖掘（liked纳入/disliked排除）
```

### 反馈操作

| 操作 | 入口 | 效果 |
|---|---|---|
| 👍 有用 / 👎 没用 | 卡片或详情弹窗 | 提取该论文的主题到 liked/disliked |
| 相关性/新颖性滑杆（1-5） | 详情弹窗 | 精细反馈参与画像提取 |
| 评语 | 详情弹窗（≤200字） | 自动学术化改写后存入 profile |
| 手动添加/删除主题 | 订阅面板 ✅/🚫 区 | 直接告诉系统你的方向 |

### 评分影响

- liked 主题 + 近期评语原文注入**评分提示词**——AI 看得到你的偏好
- liked 主题纳入**关键词挖掘**——搜索方向更聚焦
- disliked 主题从挖掘中**排除**——减少垃圾结果

### 🕸️ 知识图谱

- d3 力导向布局，节点 = 聚类，颜色 = 问题域
- 悬停节点 → 高亮关联 + 详情面板（问题域/论文数/关键词）
- **点击节点下钻** → 该聚类论文列表弹窗（推荐标签+月份）→ 点击进详情

### 📡 趋势雷达

- 周/月双粒度中文趋势报告（新方法涌现/机会点/领域迁移/争议）
- 历史归档下拉回看
- 页内「生成趋势报告」按钮（进度轮询+完成后自动加载）

### 💡 研究想法

- 输入研究想法 → AI 检索库中已有论文 → 分析可行性/新颖度/相关工作/差异化建议/风险
- 可行性/新颖度仪表盘（高/中/低彩色标识）
- 草稿自动保存（刷新不丢）

### 📰 今日简报

- 每日凌晨自动生成（AI 按主题分组整理，含必读推荐与亮点）
- 页内「生成今日简报」按钮（触发后轮询日期列表，新简报自动加载）
- GFM 表格渲染，链接协议白名单（仅 https?:/#）

## ♻️ 版本管理与自动收敛

### 分层版本戳

三个独立版本常量（`backend/ai/enhance.py` 顶部），各层独立递增：

| 版本 | 影响面 | 列 | 重跑代价 |
|---|---|---|---|
| `ENHANCE_VER` | tldr/评分/推荐 | ai_results.pipeline_version | 15-25s/篇 |
| `CARD_VER` | 知识卡片内容 | knowledge_cards.card_version | ~3s/篇 |
| `CLUSTER_VER` | 聚类分组 | knowledge_clusters.cluster_version | 几分钟/全库 |

**改哪层只递增哪个常量 → 重跑只动那层。**

### 手动重跑入口

| 入口 | 说明 |
|---|---|
| ♻️ 重跑旧版增强+卡片 | 全链重跑（慢，15-25s/篇） |
| 🗂 只重提旧版卡片 | 仅卡片层（快 5 倍，3s/篇） |
| 重跑图谱聚类 | 仅聚类层 |

### 夜间自动收敛

arxiv 抓取批完成后自动触发：
- **批量** = max(1, 旧版量 × CONVERGE_PCT%)——几何收敛
- **限时** = CONVERGE_MAX_MIN 分钟，到点即停
- **优先级**：卡片（快）→ 增强（慢）；必读/推荐排前

## 安全

### LAN 访问令牌

绑定 `0.0.0.0` 时：
- 自动生成 `LAN_ACCESS_TOKEN`（24 字节 URL-safe）
- **本机请求豁免**（127.0.0.1/::1 无需令牌）
- 局域网设备必须携带 `X-Access-Token` 请求头
- 令牌在 ⚙️ 设置面板仅对本机可见

### Host 校验

防 DNS rebinding：仅接受 `127.0.0.1`/`localhost`/`[::1]`/本机实际 IP 的 Host 头。

### 前端转义

- 论文标题/摘要/作者/venue/LLM 输出/聚类名全部经 `escAttr` 转义
- digest.js 链接协议白名单（仅 `https?:`/`#`）+ 引号转义

### LLM 提示注入防线

- GLM 专属 `thinking` 参数只在 bigmodel 端点发送
- 推荐等级/评分受白名单和整数约束
